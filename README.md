# blue-matching

## 求人の編集・募集状態

求人一覧から求人情報を編集し、募集終了または募集再開に切り替えられます。募集人数は「1〜3名（少人数・ピンポイント）」「4〜6名（チーム・中規模）」「7〜10名（大規模）」「11名以上（超大型・大量募集）」から選択でき、一覧と詳細に表示されます。勤務地も求人に登録でき、職種・勤務地・タグで検索できます。求職者プロフィールに希望勤務地を登録すると、同じ地域の求人を優先表示します（距離計算ではなく、入力地域の一致を優先し、その次に都道府県の一致を優先します）。勤務地が同程度に一致する場合は、選択タグとの合致数、選択した並び替え順の順に表示します。求人一覧は募集中のみの表示、勤務地・募集人数・給与区分・最低給与額での絞り込み、新着順・給与額順・募集人数が少ない順の並び替えに対応します。求人登録では給与表記に加え、絞り込み用の給与区分と金額を任意で登録できます。タグは複数選択でき、選択したタグのいずれかを含む求人に絞り込みます。募集終了の求人では応募ボタンを表示しません。

### Supabase の準備

求人の募集状態、勤務地、給与条件を保存するカラムを追加します。Supabase の SQL Editor で次のSQLファイルをそれぞれ一度実行してください。

- [`supabase/migrations/20261026_add_job_status.sql`](./supabase/migrations/20261026_add_job_status.sql)
- [`supabase/migrations/20261026_add_job_location.sql`](./supabase/migrations/20261026_add_job_location.sql)
- [`supabase/migrations/20261026_add_job_pay.sql`](./supabase/migrations/20261026_add_job_pay.sql)

編集・募集状態の更新には、Supabase の Row Level Security（RLS）で `published_jobs` の `UPDATE` が許可されている必要があります。実行後も更新に失敗する場合は、プロジェクトの認証・RLSポリシーを確認してください。公開鍵を使うページのため、無制限な更新ポリシーは設定しないでください。
